# Neuroverse

**Explore the Brain. Discover the Science. Experiment with Intelligence.**

Neuroverse is a planned interactive scientific learning platform combining neuroscience education, connectome exploration, graph algorithms, and reproducible computational experiments.

> **Project status:** Planning — Phase 01. The application and scientific dataset pipeline have not yet been implemented. Do not interpret concept visuals as validated biological reconstructions.

## Project direction

- **Learn:** evidence-based neuroscience and computer science lessons.
- **Explore:** investigate a clearly attributed subset of the FlyWire adult fruit fly connectome.
- **Experiment:** run graph algorithms and compare computational results.
- **Experience:** an accessible Cosmic Neuroscience interface featuring optional 3D visuals, decorative DNA helices, and subtle particles.

## Planned technology

React, TypeScript, Vite, Tailwind CSS, Three.js/React Three Fiber, Python, FastAPI, NetworkX, and SQLite (where persistence is needed). Specific packages remain subject to Phase 02 verification.

## Documentation

Phase 01 is developed on the `phase/01-product-foundation` branch. Its four planning documents cover product requirements, scientific standards, visual design, and the delivery roadmap. Once reviewed and merged, links will be added here.

## Research foundations

- Dorkenwald et al. (2024), *Neuronal wiring diagram of an adult brain*, Nature. https://doi.org/10.1038/s41586-024-07558-y
- Lin et al. (2024), *Network statistics of the whole-brain connectome of Drosophila*, Nature. https://doi.org/10.1038/s41586-024-07968-y
- FlyWire data and citation guidelines: https://home.flywire.ai/guidelines

The FlyWire FAFB v783 public data are distributed under CC BY-NC 4.0. Data reuse requires attribution and compliance with the noncommercial restriction. Scientific findings, simplified models, and purely decorative elements must be distinguished.
